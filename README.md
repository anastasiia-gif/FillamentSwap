# FilamentSwap — 3D-Printed Filament Swap Mechanism

STL models for a mechanical **filament swap system** for an FDM 3D printer: a main body with filament tubes, a spring-loaded swing arm, printer attachment brackets and dual-gear extruder loader parts.

## Parts

| File | Part |
|---|---|
| `Filament_swap_main_body_v3_with_tubes.STL` | Main body of the swap mechanism, with integrated filament tube routing |
| `Swing_arm_fillament_swap_with_many_spring_placements.STL` | Swing arm with multiple spring mounting positions for tuning the engagement force |
| `Bird_filament_swap_v3.STL` | "Bird" latch/guide component of the swap mechanism |
| `Main_attachment_v1.STL` / `Main_attachment_v2.STL` | Printer mounting bracket (two iterations) |
| `Loader 2.0 Dual Gear Extruder — filament catch / front guide / plunger` | Dual-gear extruder loader parts used for feeding the filament |

## Printing

All parts print without exotic requirements — PLA or PETG, standard layer heights. The swing arm's multiple spring placements let you experiment with spring tension without reprinting.

## Status

Working iteration v3. The v1/v2 files are kept to show the design evolution.
